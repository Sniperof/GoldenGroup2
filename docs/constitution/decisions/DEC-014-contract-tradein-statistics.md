# DEC-014: الاستبدال في العقد تصنيف إحصائي فقط

**الحالة:** معتمد
**التاريخ:** 2026-07-30

## القرار

قيمة `contracts.sale_type = 'tradein'` تصف نوع البيعة إحصائياً فقط. يحفظ العقد
الجديد معها لقطة من:

- رقم العقد القديم في `old_contract_number`.
- حالة الجهاز القديم في `old_device_condition` بقيمة `good` أو `damaged`.

رقم العقد القديم نص إحصائي وليس مفتاحاً أجنبياً إلى عقد آخر.

## حدود الأثر

حفظ أو تعديل هذا التصنيف لا:

- يغيّر حالة العقد القديم أو يغلقه أو يلغيه.
- يغيّر حالة أي سجل في `installed_devices`.
- ينشئ مهمة سحب أو تسليم أو استبدال.
- يغيّر الدفعات أو الأقساط أو الذمم أو الضمانات.

أي مسار تشغيلي لاستبدال جهاز فعلي يحتاج قراراً مستقلاً، ولا يُستنتج من
`sale_type = 'tradein'`.

## سلامة البيانات

- يلزم رقم العقد القديم وحالة الجهاز عند حفظ عقد استبدال جديد أو تعديل مسودته.
- تُمسح القيمتان عند تغيير نوع البيع إلى `direct` أو `retention`.
- تبقى سجلات الاستبدال التاريخية السابقة للقرار مقروءة حتى لو كانت بلا لقطة؛
  لا يجوز اختراع بيانات قديمة لإكمالها.
